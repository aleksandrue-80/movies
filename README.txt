Как поставить на Android (через GitHub Pages, бесплатно):
1. Создайте аккаунт на github.com и новый публичный репозиторий, например movies.
2. Загрузите в него все 6 файлов из этой папки (Add file -> Upload files).
3. Settings -> Pages -> Source: Deploy from a branch -> main / (root) -> Save.
4. Через минуту сайт будет по адресу https://ВАШ_ЛОГИН.github.io/movies/
5. Откройте этот адрес в Chrome на телефоне -> меню (три точки) -> «Установить приложение».
6. Для поиска фильмов: themoviedb.org -> Settings -> API -> ключ v3, вставьте в Настройках приложения.
